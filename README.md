# Nahom's Portfolio

A personal website designed to showcase my skills, projects, and achievements with a modern, professional aesthetic.

## Features
- **Minimalist Design**: Golden and black color theme for a clean, elegant look.
- **Interactive Animations**: Smooth transitions and dynamic visual effects.
- **Portfolio Section**: Highlighting my best projects with images and descriptions.
- **Contact Form**: PHP-powered form for direct communication.
- **Responsive Layout**: Optimized for desktop and mobile viewing.
- **Slider Integration**: Dynamic sliders for seamless navigation.

## Technologies Used
- **Frontend**: HTML, CSS, JavaScript.
- **Backend**: PHP for handling form submissions.
